# P2-T05 — WindowBase sandbox

Status: passed
Assignee: Compose 2.5
Reviewer: Grok 4.6
Phase: 2

## 目的

sandbox で window 一枚が表示・操作・破棄できることを示す。Phase 2 完了条件。NineSlice / Message / TextWindowBase は入れない。

移植元の参照:

- `examples/scenes/WindowBaseScene.ts` — WindowBase + content 内 overflow 円 + `update`
- `examples/scenes/PaddingChromeScene.ts` — `setPadding` と chromeless（`backgroundAlpha: 0`, `borderWidth: 0`）

## 対象

`examples/main.ts` を WindowBase デモに更新。`index.html` は必要なら短い操作説明を足してよい。

起動手順:

1. 既存どおり `Application.init`（960×540、`roundPixels: true`、`antialias: false`）
2. `createPixiWindowHost(app, { logicalWidth: 960, logicalHeight: 540 })`
3. `preloadDefaultBitmapFont()`
4. `new WindowBase(host, { x: 80, y: 60, width: 420, height: 180 })`
5. content に overflow 円（Pixi `Graphics`、v8 shape-then-fill / stroke。半径 ~40）。`update` で x を整数 sin オフセット（移植元 WindowBaseScene）
6. content に BitmapText `"こんにちは ABC 123"`（fontFamily は asset key、fontSize 12、nearest）。P2-T01 の文字サンプルを残す
7. `void window.open()`（await しなくてよい。`ignoreTransitionCancellation` は internal なので sandbox では `.catch(() => {})` でキャンセルを捨ててよい）
8. `window.activate()`
9. `app.ticker.add` で `window.update(ticker.lastTime, ticker.deltaMS)` と overflow アニメ。window が destroy 済みなら update しない
10. ブラウザ `resize` で renderer を `#app` client サイズへ（既存）

キーボード（`window` の `keydown`、`KeyboardEvent.code`。PixiWindowInput にデモ専用キーを足さない）:

| code | 操作 |
|---|---|
| `KeyR` | `setSize` で 420×180 と 520×240 をトグル |
| `KeyP` | padding を 0 → 8 → 16 → 0 |
| `KeyC` | chromeless トグル。on: `setTheme({ backgroundAlpha: 0, borderWidth: 0 })`。off: 既定の背景/枠へ戻す |
| `Space` | 途中反転。phase が `open` / `opening` なら `close()`、それ以外は `open()`。promise は catch |
| `KeyX` | `destroy()`。以降キーは no-op |

`beginFill` / `phaser` / `PIXI.Text` 禁止。

## テスト

`tests/examples/sandbox-entry.test.ts` を更新:

- `WindowBase` と `createPixiWindowHost` がある
- `window.update` と `ticker` がある
- `setSize` / `setPadding` / `setTheme` / `destroy` がある
- `KeyR` `KeyP` `KeyC` `Space` `KeyX` がある
- Graphics + BitmapText が残る
- `beginFill` / `phaser` が無い

`tests/examples/bitmap-font-spike.test.ts` の sandbox 検査は、BitmapText が main に残るなら維持。
