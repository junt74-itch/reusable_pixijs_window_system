### `docs/SPECIFICATION.md`

移植元 `docs/SPECIFICATION.md` の契約を PixiJS 語に置換した **目標仕様** にする。先頭に実装状況バナーを置く:

> Implementation status: Phase 0 scaffold. 公開コードは `VERSION` と最小 sandbox のみ。以下は移植完了時の規範であり、いまの `src/` の実装範囲ではない。

必須の置換:

- Phaser 4 Scene → `PixiWindowHost`（未実装と明記）
- `PhaserWindowInput` → `PixiWindowInput`
- `scene.load.bitmapFont` → consumer 所有の `Assets.load`（詳細は Phase 2 spike）
- Canvas GeometryMask fallback → **提供しない**（Drop）
- Phaser `BitmapText` → Pixi `BitmapText`（canvas/CSS/OS font と Pixi `Text` は禁止）
- Scene shutdown → host destroy

契約そのもの（say/choose の 1 回 settle、typed error、padding、RichText、ownsInput、focus が singleton でないこと）は維持する。

各主要節の末尾に `Status: unimplemented (Phase N)` を付ける。Phase 番号は [PORTING_PLAN.md](../PORTING_PLAN.md) に合わせる。
