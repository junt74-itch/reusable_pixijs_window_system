# P0-T02 — Package consumer and check gate

Status: passed
Assignee: Compose 2.5
Reviewer: Grok 4.6
Phase: 0

## 目的

空ライブラリのまま、移植元と同じ `bun run check` 骨格（unit → typecheck → build → package → consumer typecheck）を通す。Window API は追加しない。

## 対象

作成・更新してよいファイル:

- `package.json` の scripts のみ（dependencies は変えない）
- `tsconfig.consumer.json`
- `src/README.md`（空 barrel の入口説明。未実装 module を完成したように書かない）
- `examples/consumer/readme-example.ts`
- `examples/consumer/submodule-source.ts`
- `tests/package/public-exports.test.ts`
- `tests/package/repository-access.test.ts`
- `README.md` に package / consumer の説明を 1 段落足してよい。`docs/SUBMODULE.md` は未作成なので必須リンクにしない

`package.json` scripts を次へ更新する（既存 script は残す）:

- `"test:package": "bun test tests/package"`
- `"typecheck:consumer": "tsc --noEmit -p tsconfig.consumer.json"`
- `"check": "bun run test:unit && bun run typecheck && bun run build && bun run test:package && bun run typecheck:consumer"`

`test:unit` は `bun test tests/scaffold.test.ts` のまま。package テストは `test:unit` に混ぜない。

`tsconfig.consumer.json`:

```json
{
  "extends": "./tsconfig.json",
  "compilerOptions": {
    "paths": {
      "reusable-pixijs-window-system": ["./dist/index.d.ts"]
    }
  },
  "include": ["examples/consumer/**/*.ts"]
}
```

主 `tsconfig.json` の `include` に `examples` を足さない。consumer は `typecheck:consumer` だけが型検査する。

`examples/consumer/readme-example.ts` は package 名からの import のみ。`VERSION` を使い、Phaser / Window / Scene を書かない。

`examples/consumer/submodule-source.ts` は `from "../../index.ts"` のみ。`../../src/` への deep import 禁止。

`src/README.md` は入口が root `index.ts` と `src/index.ts` であること、deep import 非保証、いまの公開値は `VERSION` のみ、Pixi 依存は後 Phase で adapter 境界に置くこと、を短く書く。`docs/SPECIFICATION.md` が無いので必須リンクにしない。`docs/API.md` もまだ無い。

### `tests/package/public-exports.test.ts`

移植元の意図を空 surface に合わせる。少なくとも:

1. `package.json` の `exports` / `module` / `types` が `./dist/index.js` と `./dist/index.d.ts`
2. `dist/index.js` が `VERSION` を含む
3. `dist/index.js` に `from "phaser"` も `phaser/dist/phaser.esm` も無い
4. `dist/index.js` の長さは 200_000 未満
5. `dist/index.d.ts` に `\bany\b` が無く、`VERSION` がある
6. barrel が internal helper（`sayPreflight`, `ScrollContentClip`, `flattenRichText` など移植元 FORBIDDEN 名）を export していない
7. `src/` に `from "phaser"` / `from 'phaser'` が無い

`from "pixi.js"` が bundle に含まれることは **要求しない**（空 barrel は pixi を import しない）。

### `tests/package/repository-access.test.ts`

1. root `index.ts` が `export * from "./src/index.ts"` を含み、`./src/core/` や `./src/message/` を含まない
2. `examples/consumer/submodule-source.ts` が `from "../../index.ts"` を含み、`../../src/` を含まない
3. `docs/README.md` と `src/README.md` が存在する
4. ルート README が `docs/README.md` を指す

`docs/SPECIFICATION.md` / `docs/API.md` / `docs/SUBMODULE.md` / `docs/plan/` は **まだ要求しない**（P0-T04）。

## 非対象

- Window / Host / Input / sandbox（P0-T03）
- SPECIFICATION / API / SUBMODULE / checklist 本文（P0-T04）
- フォント、Three.js
- `VERSION` 以外の公開 export
- `phaser` 追加、`pixi.js` 版の変更
- `tsconfig.json` の strict フラグ変更
- 方針 md、PORTING_BASELINE.md、PORTING_PLAN.md、PROGRESS.md、API_COMPATIBILITY_MAP.md の改稿
- git commit / push

## 受入条件

1. `bun run check` が unit + typecheck + build + package + consumer を一括で exit 0
2. `bun run test:package` が公開面と repository-access を検証する
3. `bun run typecheck:consumer` が `examples/consumer/*.ts` を `dist/index.d.ts` 経由で通す
4. consumer が Window / Phaser API を使っていない
5. `src/` と `dist/` に Phaser が無い
6. 公開 export は引き続き `VERSION` のみ

## 実行コマンド

```bash
bun run check
```

`typecheck:consumer` は build 後の `dist/index.d.ts` を見る。check の順序を入れ替えない。
