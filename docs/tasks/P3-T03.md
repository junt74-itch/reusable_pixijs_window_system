# P3-T03 — ScrollableWindow

Status: passed
Assignee: Compose 2.5
Reviewer: Grok 4.6
Phase: 3

## 目的

`ScrollableWindow` を Pixi に移す。`ScrollController` + 内側 `scrollBody` + `ContentClipper` クリップ + 任意 scrollbar / overflow 矢印。wheel / PageUp / PageDown / drag は既存 `bindScrollInput`。`WindowBase` に scroll API を足さない。`SelectableWindow` は作らない。

- `src/scroll/ScrollableWindow.ts`
- `src/scroll/ScrollContentClip.ts`
- `src/scroll/ScrollbarRenderer.ts`
- `src/scroll/ScrollOverflowIndicators.ts`
- `tests/scroll/ScrollableWindow.test.ts` の **ScrollableWindow / bindScrollInput / ScrollbarRenderer / scrollVisibility** 部分（`SelectableWindow` describe はコピーしない）

ADR: `docs/adr/0004-scroll-composition.md`

既存の landed（触らなくてよい）: `ScrollController`、`bindScrollInput`、`scrollChrome`、`scrollVisibility`。

## 配置

`src/scroll/**` と `src/core/**` に `from "pixi.js"` を足さない。Pixi クラスは `src/pixi/`:

| クラス | パス |
|---|---|
| `ScrollableWindow` | `src/pixi/ScrollableWindow.ts` |
| `ScrollContentClip` | `src/pixi/ScrollContentClip.ts` |
| `ScrollbarRenderer` | `src/pixi/ScrollbarRenderer.ts` |
| `ScrollOverflowIndicators` | `src/pixi/ScrollOverflowIndicators.ts` |

第 1 引数は `PixiWindowHost`。`this.scene` は作らない。`ContentClipper` は `new ContentClipper(host)`。

## Phaser → Pixi

| Phaser | PixiJS 8.20.1 |
|---|---|
| `scene.add.container` | `new Container()` + `addChild` |
| `scene.add.graphics` | `new Graphics()` または `createPixiGraphicsFactory(parent)` の `GraphicsLike`。v8 `rect().fill()` / triangle は shape-then-fill。`beginFill` 禁止 |
| `scrollBody.setPosition(-offset, 0)` | `position.set`。整数 `Math.trunc(-offset)` |
| `viewport.setSize` | Pixi Container に無い。clip は `ContentClipper.updateBounds` だけ（P2-T03） |
| mask | 既存 `ContentClipper`。**`visible = false` を mask に戻さない** |

公開メソッド維持: `getScrollBody`、`getScrollController`、`setScrollContentSize`、`setScrollOffset`、`getScrollOffset`。`ScrollableWindowOptions`（`showScrollbar?` + `ScrollControllerOptions` + `WindowBaseOptions`）。

`onLayoutChanged` で viewport / clip / presentation を同期。destroy は subscription → input binding → scrollbar → clip → indicators → `super.destroy()`。

`cullChildren` は scrollBody の `BitmapText` だけ（移植元どおり）。他の Graphics は cull しない。

overflow 矢印は content 上の overlay（chrome ではない）。

## テスト

WebGL / `Application.init` 禁止。stub host は `tests/pixi/WindowBase.test.ts` と同じ。入力は `tests/helpers/ManualWindowInput.ts`。

`tests/pixi/ScrollableWindow.test.ts`（新規）:

1. `extends WindowBase`。`src/pixi/WindowBase.ts` に `scroll` が無い
2. `getScrollBody()` の parent 経路に clip viewport がある。`setScrollContentSize` 後 `setScrollOffset` で body `y === Math.trunc(-offset)`（axis y）
3. `ManualWindowInput` + `activate()` のあと `pageDown` / wheel / drag で offset が増える（`canConsumeInput` が true になるよう open+activate+enable）
4. `showScrollbar: true` で track/thumb Graphics が content に載る。`isPointerCaptured` がある
5. content より小さい viewport で overflow 時に indicators が存在する（visible 切替でよい）
6. `from "phaser"` / `beginFill` / `SelectableWindow` が無い
7. 移植元の `createScrollbarContentDragGate` / `bindScrollInput` 契約テストは `tests/scroll/ScrollableWindow.test.ts` に既にあれば維持。無ければ pixi テストに gate だけ残す（`src/scroll` の既存 test を壊さない）
