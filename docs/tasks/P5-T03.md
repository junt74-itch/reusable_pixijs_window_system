## 配置

| もの | パス |
|---|---|
| `bindFocusControllerToHost` | `src/focus/bindHostDestroy.ts` |

シグネチャ:

```ts
bindFocusControllerToHost(
  host: PixiWindowHost,
  controller: WindowFocusController,
): () => void
```

第 1 引数は `PixiWindowHost`。`import type { PixiWindowHost } from "../host/types.ts"` は可。このファイルに `from "pixi.js"` / `from "phaser"` を書いてはいけない。偽 Phaser 型禁止。`any` 禁止。`this.scene` 禁止。

Phaser は `SHUTDOWN` と `DESTROY` の両方で `dispose()`。Pixi は **`host.onDestroy` 1 本**（host に shutdown イベントは無い。作らない）。

返した unbind は Phaser と同じ:

1. `onDestroy` 購読を外す
2. `controller.dispose()` を呼ぶ

`dispose` は既に冪等。host が既に destroyed なら `onDestroy` は即 handler を呼ぶ（既存 host 契約）。bind 時点で即 `dispose` してよい。

unbind 後の `host.destroy()` で binder が二重に `dispose` しても落ちないこと（購読解除が本筋。dispose 再入は no-op）。

## 意味論（ADR 0005。実装で変えない）

- 非 modal `acquire(window)` は stack を置き換える。前の window を deactivate してから新しい window を activate
- `acquire(window, { modal: true })` は push。top だけ activate。下は deactivated
- `canConsumeInput()` は local predicate（`open` + visible + active + enabled）。modal フラグを `WindowBase` に足さない
- Window は controller を import しない
- dimmer は controller / WindowBase / binder のどれも所有しない。`FocusSnapshot.modal` を application が見る
