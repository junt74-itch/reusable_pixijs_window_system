## 目的

## 移植元

`/tmp/reusable_phaser_window_system/src/core/WindowBase.ts`（commit `7cfd315`）。**公開メソッドと状態遷移は維持。** Phaser DisplayObject API だけ置換。

`protected readonly host: PixiWindowHost`。`scene` フィールドは作らない。

## Phaser → Pixi 置換表

| Phaser | PixiJS 8.20.1 |
|---|---|
| `scene.add.container(x, y)` | `new Container()` + `position.set(x, y)`。root は `host.stage.addChild(root)` |
| `root.add(content)` | `root.addChild(content)`。順序: renderer が chrome を先に載せ、その後 content |
| `setScale(1, scaleY)` | `root.scale.set(1, scaleY)` |
| `setPosition` | `position.set`。整数 `Math.trunc` 維持 |
| `setVisible` | `visible =` |
| `setAlpha` | `alpha =` |
| `setDepth` | `zIndex =`。`host.stage.sortableChildren = true` を depth 設定時または構築時に 1 回 |
| `root.destroy(true)` | `root.destroy({ children: true })` |
| `content.getLocalPoint` | `content.toLocal` |
| world 変換 | `content.toGlobal` |
| `scene.events SHUTDOWN/DESTROY` | `host.onDestroy(() => this.destroy())` |
| `resolveWindowRenderer(..., { scene, root })` | `{ host, root }` |
| `new ContentClipper(scene)` | `new ContentClipper(host)` |

**ticker に自動 subscribe しない。** 移植元どおり `update(time, delta)` は呼び出し側（sandbox / ゲーム）が呼ぶ。

openness の縦 center 固定計算は移植元 `applyOpennessPresentation` をそのまま。

`WindowBaseOptions`: `input?`, `ownsInput?`, `createRenderer?`。createRenderer の context は `{ host, root }`。

構築直後: phase `closed`、openness `0`、`scale.y === 0` のため見えない。`open(0)` で同期オープン。`open()` は `activate()` を兼ねない。

destroy 順: deactivate → destroyed フラグ → cancelOwnedOperations → onBeforeDestroy → host onDestroy 解除 → ownsInput なら input.dispose → clipper.destroy → renderer.destroy → root.destroy。2 回目 no-op。

破棄後の操作は `WindowDestroyedError`。

## テスト

`tests/pixi/WindowBase.test.ts`。WebGL / `Application.init` 禁止。

stub host: `stage` は **実** `Container`（addChild のため）。ticker は no-op stub。canvas/renderer は T02 と同様の stub。`createPixiWindowHost` の実 Application は使わなくてよい。

必須ケース:

1. 構築直後 `getPhase() === "closed"`、`getOpenness() === 0`、`root.scale.y === 0`
2. `await open(0)` で phase `open`、openness `1`、`scale.y === 1`
3. `canConsumeInput()` は open + visible + active + enabled のときだけ true
4. show/hide が `visible` と root.visible に効く（openness 0 では root.visible は false のまま — 移植元どおり `visible && scaleY > 0`）
5. activate/deactivate
6. `setSize` / `setPadding` で content bounds が変わる
7. destroy は冪等。destroy 後の `open` は `WindowDestroyedError`
8. `host.destroy()` が window を destroy する
9. `createRenderer` 注入が `resolveWindowRenderer` を通る（Fake GraphicsFactory 可）
10. ソースに `from "phaser"` が無い

既存 `tests/core/WindowBase.lifecycle.test.ts`（engine-free）は残す。
