## 目的

エンジン非依存の `WindowInputAdapter` 契約と、unit test 用 `ManualWindowInput` を移す。`PixiWindowInput`（Browser / Pixi events）は Phase 2。

## 移植元

- commit `7cfd3156a5184193fe9e9e63958e5416d277e37e`
- `/tmp/reusable_phaser_window_system` があればそれを読む。本リポジトリへ Phaser 版を入れない。

## 対象

**そのままコピー（ロジック変更禁止）:**

- `src/input/types.ts`
- `src/input/WindowInputAdapter.ts`
- `tests/helpers/ManualWindowInput.ts`

**テスト:** `tests/input/ManualWindowInput.test.ts` をコピーするが、末尾の `describe("PhaserWindowInput wheel and drag contract")` **は捨てる**。あのブロックは `src/input/PhaserWindowInput.ts` を読む検査であり Phase 2。`ManualWindowInput` の describe だけ残す。

**更新:**

- `src/index.ts` — 移植元と同じく **type** として:
  - `WindowInputAction`, `WindowInputPhase`, `WindowInputSource`
  - `WindowActionEvent`, `WindowPointerEvent`, `WindowWheelEvent`, `WindowDragPhase`, `WindowDragEvent`
  - `WindowActionListener`, `WindowPointerListener`, `WindowWheelListener`, `WindowDragListener`, `WindowInputSubscription`
  - `WindowInputAdapter`
- `BaseWindowInputAdapter` と `ManualWindowInput` は **公開しない**
- `package.json` の `test:unit` に `tests/input` を足す
- `tests/package/public-exports.test.ts` — 新 type 名が d.ts にあること。`ManualWindowInput` / `BaseWindowInputAdapter` / `PhaserWindowInput` / `PixiWindowInput` が barrel に無いこと
- `examples/consumer` — 必要なら `WindowInputAdapter` 型だけ。具象 input クラスは使わない
- `src/README.md` に `input/` を追記
- `docs/API.md` の Current surface に type を足す。`PixiWindowInput` は Planned のまま
