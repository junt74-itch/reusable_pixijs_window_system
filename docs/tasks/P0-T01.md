# P0-T01 — Toolchain and empty library

Status: passed
Assignee: Compose 2.5
Reviewer: Grok 4.6
Phase: 0

## 目的

空の TypeScript ライブラリとして、Bun + Vite + TypeScript 7 + pixi.js 8.20.1 で build が通る状態を作る。Window 実装はまだしない。

## 対象

作成してよいファイル:

- `package.json`
- `bun.lock`（`bun install` の結果）
- `tsconfig.json`
- `tsconfig.build.json`
- `vite.config.ts`
- `.editorconfig`（移植元と同じ）
- `.gitignore`（`node_modules/`, `dist/`, `.vite/`, `*.tsbuildinfo`, `*.log`, `.DS_Store` を含む）
- `src/index.ts`
- `index.ts`（`export * from "./src/index.ts"` のみ）
- `tests/scaffold.test.ts`
- `README.md` の最短導線を、本リポジトリ向けに更新（未実装 API を完成したように書かない）

`package.json` 要件:

- `"name": "reusable-pixijs-window-system"`
- `"version": "0.0.0"`
- `"private": true`, `"type": "module"`, `"sideEffects": false`
- `"module"` / `"types"` / `"exports"."."` は `./dist/index.js` と `./dist/index.d.ts`
- `dependencies`: `"pixi.js": "8.20.1"` のみ
- `devDependencies`: `"@types/bun": "1.4.0"`, `"typescript": "7.0.2"`, `"vite": "8.2.2"`
- scripts:
  - `"dev": "vite"`
  - `"test": "bun test"`
  - `"test:unit": "bun test tests/scaffold.test.ts"`
  - `"typecheck": "tsc --noEmit"`
  - `"build": "vite build && tsc -p tsconfig.build.json --emitDeclarationOnly"`
  - `"check": "bun run test:unit && bun run typecheck && bun run build"`

`tsconfig.json` は移植元と同じ compilerOptions（strict / noUncheckedIndexedAccess / exactOptionalPropertyTypes / Bundler / allowImportingTsExtensions / verbatimModuleSyntax / types: bun）。`include` は `src`, `tests`, `vite.config.ts`。

`tsconfig.build.json` は移植元と同じく `src` → `dist` の emitDeclarationOnly。

`vite.config.ts` は library ES build、entry `src/index.ts`、`external: ["pixi.js"]`。

`src/index.ts` は次だけ:

```ts
/** Scaffold version. Window exports land in later phases. */
export const VERSION = "0.0.0";
```

`tests/scaffold.test.ts` は Bun test runner が動くことと、`VERSION` が `"0.0.0"` であることを検証する。

## 非対象

- Window / Host / Input の実装
- `examples/` sandbox（P0-T03）
- package consumer と `typecheck:consumer`（P0-T02）
- SPECIFICATION / API 本文の複製（P0-T04）
- フォント asset と `font:sync`
- `phaser` の追加、`any` や偽 Phaser 型
- 公開 API の追加（`VERSION` 以外）
- 方針 md の改稿
- git commit / push

## 受入条件

1. `phaser` が `package.json` にも source にも無い
2. `pixi.js` が `8.20.1` で lock されている
3. `bun run test:unit` が合格
4. `bun run typecheck` が合格
5. `bun run build` が `dist/index.js` と `dist/index.d.ts` を出し、bundle が `VERSION` を含み Phaser を inline しない
6. `bun run check` が上記を一括で通す
7. root `index.ts` は `src/index.ts` だけを再 export する

## 実行コマンド

```bash
bun install
bun run check
```
