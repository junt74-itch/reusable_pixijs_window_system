## 文書が満たすこと

1. 正式な導入方法は Git submodule のみ。npm / Git URL install が使えるように見えない
2. 入口は root `index.ts`。`src/**` deep import 禁止
3. PixiJS は consumer が `peerDependencies` 範囲で入れ、runtime を共有する
4. フォントは consumer が配置・load する。`DEFAULT_BITMAP_FONT_ASSET` は sandbox 用
5. 最小実働例は `examples/consumer/minimal-submodule-runtime.ts`。README 掲載コードと一致
6. `examples/consumer/readme-example.ts` は **npm 導入例ではない**。build 後の package 名を型検査する fixture
7. `examples/consumer/submodule-source.ts` は barrel surface の型検査 fixture。実働例ではない
8. `examples/main.ts` は library 内部 sandbox
9. Three.js は別 canvas overlay が標準、共有 context は任意。Phase 7 で標準化しない
10. CI badge を足すなら workflow 名 `check` と一致させる

```markdown
[![check](https://github.com/junt74-itch/reusable_pixijs_window_system/actions/workflows/check.yml/badge.svg)](https://github.com/junt74-itch/reusable_pixijs_window_system/actions/workflows/check.yml)
```

リポジトリの GitHub path が違う場合は実際の origin に合わせ、推測で org 名を変えない。origin が取れない・未公開なら badge を省略し、未解決事項に書く。
