# P6-T01 — Three.js 別 canvas overlay 標準例

Status: passed
Assignee: Compose 2.5
Reviewer: Grok 4.6
Phase: 6

## 目的

方針どおり **標準統合は別 canvas の重ね合わせ**。Three.js が 3D を描き、その上に PixiJS canvas を CSS で載せる。`createPixiWindowHost` で既存 Window API を動かす。

Pixi 公式ガイドの **単一 WebGL context 共有**（`pixiRenderer.init({ context: threeRenderer.getContext() })` / `resetState`）は **このタスクでは禁止**。それは P6-T02（任意例、標準にしない）と人間判断。

`src/` の公開 API を増やさない。`examples/main.ts` の say→choose は **変えない**。

## 配置

| もの | パス |
|---|---|
| overlay HTML | リポジトリ直下 `three-overlay.html`（Vite `root: "."`。URL は `http://localhost:5173/three-overlay.html`） |
| overlay entry | `examples/three-overlay.ts` |
| ファイル契約テスト | `tests/examples/three-overlay-entry.test.ts` |

`three` は **`devDependencies` のみ**。版は **`0.185.1` を exact pin**。`dependencies` に `three` を足さない。library `vite build` の `external` に three を足す必要は無い（src が three を import しないため）。

## 重ね方

1. wrapper（`#overlay-root`）を `#app` 相当の letterbox 対象にする。論理サイズ **960×540**。既存 sandbox と同じく **CSS 整数 letterbox**。`app.renderer.resize` で論理サイズを変えない
2. **下**: Three.js `WebGLRenderer` の `domElement`（立方体など最小 3D。アニメーションして「生きている」こと）
3. **上**: PixiJS `Application` の **独自 canvas**（`app.init` に Three の context を渡さない）。背景は透明（`backgroundAlpha: 0`）。`roundPixels: true`、`antialias: false`
4. 上の canvas だけ pointer を受ける（下は `pointer-events: none`）
5. 両方の canvas は同じ CSS 幅高さ。`image-rendering: pixelated` は Pixi 側に合わせてよい
6. `createPixiWindowHost(app)` のあと `WindowBase` または `MessageWindow` を **1 枚**。BitmapText を出すなら既存 `preloadDefaultBitmapFont`。NineSlice PNG は足さない
7. Pixi ticker で window `update`。Three の cube 回転は three の render loop か同じ rAF。**`threeRenderer.resetState` / Pixi `resetState` / 共有 context は書かない**

入力座標: pointer は上の Pixi canvas 上なので `PixiWindowInput` の既存経路で足りる。変換を新発明しない。

destroy: overlay ページを閉じる以外の明示 destroy デモは任意。window は Application / three renderer を destroy しない（既存所有権）。

## テスト

WebGL / `Application.init` / `WebGLRenderer` 実起動は禁止。

`tests/examples/three-overlay-entry.test.ts`（新規）:

1. `three-overlay.html` が `/examples/three-overlay.ts` を module script で読む
2. `examples/three-overlay.ts` が `from "three"` と `createPixiWindowHost` と `app.init` を含む
3. ソースに `getContext()` を Pixi `init` へ渡す経路が無い。`resetState` が無い
4. ソースに `phaser` / `beginFill` が無い
5. `package.json` の `dependencies` に `three` が無く、`devDependencies.three` が `"0.185.1"`
6. `src/` に `from "three"` が無い（walk または overlay が src を three 経由で汚していないこと）

既存 `tests/examples/sandbox-entry.test.ts` は壊さない（`examples/main.ts` が say→choose のまま）。

`package.json` `test:unit` は `tests/examples` が既にあるので新しいファイルは自動で拾われる。script 列を増やさない。
