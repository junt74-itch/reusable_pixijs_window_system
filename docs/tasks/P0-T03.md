# P0-T03 — Minimal Pixi sandbox

Status: passed
Assignee: Compose 2.5
Reviewer: Grok 4.6
Phase: 0

## 目的

PixiJS v8 の `Application` が sandbox で起動し、色付き矩形を描き、resize できることを示す。Window ライブラリ本体はまだ実装しない。`PixiWindowHost` も作らない。

## 対象

作成・更新してよいファイル:

- `index.html`
- `examples/main.ts`
- `tests/examples/sandbox-entry.test.ts`
- `tsconfig.json` の `include` / `exclude` のみ（compilerOptions は変えない）
- `package.json` の `test:unit` のみ（他 script・dependencies は変えない）
- `README.md` に `bun run dev` と sandbox URL を足してよい
- `vite.config.ts` は **library build を維持**したまま、dev に必要な最小オプションだけ足してよい

`index.html`:

- `lang="ja"`
- `#app` を canvas の parent にする
- `script type="module" src="/examples/main.ts"`
- タイトルは PixiJS Window System であること。Phaser とは書かない

`examples/main.ts`（PixiJS v8 契約）:

- `new Application()` のあと **`await app.init({...})`**。v7 の constructor オプションは使わない
- 論理サイズは移植元 sandbox に合わせ **960×540**
- `roundPixels: true`、`antialias: false`
- background は任意の暗い色
- `#app` に `app.canvas` を載せる
- chrome の仮として `Graphics` で矩形 1 つ（位置 40,40、サイズ 520×160 程度）。v8 は **shape-then-fill**（`rect(...).fill(...)` / `stroke(...)`）。v7 の `beginFill` は使わない
- `window` の `resize` で renderer を `#app` の client サイズへ合わせる。window 座標の論理サイズ方針は Host 導入までこの sandbox 内に閉じる
- `phaser` を import しない
- `src/` の Window API を実装・import しない。`VERSION` の表示は任意
- Three.js を導入しない

`tsconfig.json`:

- `examples/main.ts` が `bun run typecheck` に入るようにする
- `examples/consumer` は **含めない**（`typecheck:consumer` 専用のまま）
- 例: `include` に `examples` を足し、`exclude` に `examples/consumer` を置く

`package.json`:

- `"test:unit": "bun test tests/scaffold.test.ts tests/examples"`
- `check` の順序は変えない

`tests/examples/sandbox-entry.test.ts`（WebGL は起動しない。ファイル契約の検査）:

1. `index.html` が `/examples/main.ts` を module script で読む
2. `examples/main.ts` が `Application` と `app.init` を含む
3. `examples/main.ts` が `Graphics` と `fill` を含む
4. `examples/main.ts` が `resize` を扱う
5. `examples/main.ts` と `index.html` に `phaser` が無い
6. `examples/main.ts` が `beginFill` を使わない

`bun run dev` をこのタスクの完了条件にしない（ブラウザ操作はレビュー側）。自動ゲートは `bun run check`。

## 非対象

- `PixiWindowHost` / `WindowBase` / Input / BitmapText / mask
- `src/index.ts` への公開 API 追加（`VERSION` 以外）
- フォント asset、`Assets.load`
- Three.js overlay
- `?scene=` の複数 route（P2 以降）
- SPECIFICATION / API / SUBMODULE 本文（P0-T04）
- `phaser` 追加、`pixi.js` 版変更
- library `vite build` を app bundle に切り替えること（`dist/index.js` は引き続き library）
- 方針 md と進行文書の改稿
- git commit / push

## 受入条件

1. `bun run check` が exit 0（unit に examples 検査が含まれる）
2. `bun run typecheck` が `examples/main.ts` を含み、`examples/consumer` を含まない
3. `bun run build` が library `dist/index.js` のまま（sandbox を dist に束ねない）
4. 公開 export は `VERSION` のみ
5. sandbox が Phaser を使わない
6. `Application.init` が非同期で呼ばれる

## 実行コマンド

```bash
bun run check
```
