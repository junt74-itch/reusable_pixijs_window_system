# P2-T02 — PixiWindowHost

Status: passed
Assignee: Compose 2.5
Reviewer: Grok 4.6
Phase: 2

## 目的

`Phaser.Scene` の置換境界として `PixiWindowHost` と `createPixiWindowHost(app)` を入れる。Window は Application に直接結合しない。`WindowBase` / Graphics factory / Input / clipper はまだ入れない。

## 根拠

- [PORTING_BASELINE.md](../../PORTING_BASELINE.md): Host = Renderer / stage root / canvas / ticker / logical size
- 方針: `createPixiWindowHost(app)` は推奨ヘルパー。座標は logical pixel
- 移植元 `WindowBase` が Scene から使うもの: `scene.add.container`（→ `host.stage` に載せる）、`SHUTDOWN`/`DESTROY`（→ `host.onDestroy`）

## 公開 API（今回 landing）

`src/host/` に置く（`pixi/` ではない。Window 描画クラスはまだ無い）。

```ts
export interface PixiWindowHost {
  readonly stage: Container;
  readonly renderer: Renderer;
  readonly canvas: HTMLCanvasElement;
  readonly ticker: Ticker;
  readonly logicalWidth: number;
  readonly logicalHeight: number;
  readonly resolution: number;
  isDestroyed(): boolean;
  onDestroy(handler: () => void): () => void;
  destroy(): void;
}

export interface PixiWindowHostOptions {
  readonly logicalWidth?: number;
  readonly logicalHeight?: number;
}

export function createPixiWindowHost(
  app: Application,
  options?: PixiWindowHostOptions,
): PixiWindowHost;
```

契約:

- `logicalWidth` / `logicalHeight` は整数。省略時は `Math.trunc(app.screen.width)` / `height`（無ければ renderer の幅高さ）
- 非正の logical size は `WindowLayoutError`
- `stage` / `canvas` / `ticker` / `renderer` が欠けたら `WindowConfigError`（silent fallback 禁止）
- `destroy()` は購読 handler を **1 回**呼ぶ。`Application.destroy` は呼ばない（app 所有者の責任）
- 2 回目の `destroy()` は no-op。`isDestroyed()` は true
- `onDestroy` の戻り値は unsubscribe。destroy 済み host への `onDestroy` は直ちに handler を呼ばず、購読もしない（または destroy 済みなら即時呼ぶ、のどちらかをテストで固定。推測で両方やらない。推奨: **subscribe せず即時に handler を呼ぶ** — 既存 window が後から登録しても漏れない）
- window 座標は logical pixel。devicePixelRatio を window に漏らさない

Pixi の具象型（`Application`, `Container`, `Renderer`, `Ticker`）は `pixi.js` から import してよい。偽型禁止。

## テスト

`tests/host/createPixiWindowHost.test.ts`（WebGL / `Application.init` は起動しない）:

- stub `Application`（`stage` / `renderer` / `canvas` / `ticker` / `screen`）で factory を呼ぶ
- logical size 省略時は screen を trunc
- 明示 options が優先
- 非正サイズは `WindowLayoutError`
- destroy で handler が一度だけ走る。app.destroy 相当は呼ばない
- unsubscribe 後は destroy しても呼ばない
- destroy 後の `onDestroy` は即時 handler

stub は bun で DOM/WebGL なしで動く plain object。`new Application()` や jsdom は使わない。
