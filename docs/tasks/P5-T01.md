# P5-T01 — Command / Help

Status: passed
Assignee: Compose 2.5
Reviewer: Grok 4.6
Phase: 5

## 目的

`CommandWindow.chooseCommands` と `HelpWindow.setHelp` を Pixi に移す。Command は Phaser と同じく `SelectableWindow` を継承する。Help は `TextWindowBase` で **pageIndex === 0 だけ描画**。Log / Document / NineSlice / focus bind は作らない。

## 移植元

`/tmp/reusable_phaser_window_system` commit `7cfd3156a5184193fe9e9e63958e5416d277e37e`:

- `src/command/types.ts`
- `src/command/commandItems.ts`
- `src/command/CommandWindow.ts`
- `src/help/HelpWindow.ts`
- 対応テストがあれば同等の契約を残す

既存 landed を変えない: `SelectableWindow`、`ChoiceWindow`、`MessageWindow`、`TextWindowBase`。

## 配置

engine-free は `src/command/`（pixi import 禁止）。Pixi クラスは `src/pixi/`。`src/help/` を新設して Help の純粋部分だけ置く必要は無い（Help は描画クラスだけなら `src/pixi/HelpWindow.ts` で足りる）。

| もの | パス |
|---|---|
| `CommandItem` / `CommandResult` / `CommandBusyError` / `CommandConfigurationError` | `src/command/types.ts` |
| `assertCommandChoiceReady` / `toSelectableCommands` | `src/command/commandItems.ts`（barrel に出さない） |
| `CommandWindow` / `CommandWindowOptions` | `src/pixi/CommandWindow.ts` |
| `HelpWindow` | `src/pixi/HelpWindow.ts` |

第 1 引数 `PixiWindowHost`。`this.scene` 禁止。偽 Phaser 型禁止。`any` 禁止。

## Phaser → Pixi

| Phaser | PixiJS 8.20.1 |
|---|---|
| Command の BitmapText / Graphics | 既存 `SelectableWindow` 経路。CommandWindow に pixi 描画を増やさない |
| Help `layoutTextContent` + `renderLines` | 既存 `TextWindowBase`。`layout.lines.filter((line) => line.pageIndex === 0)` を維持 |
| `onHighlight` | scene 所有フック。CommandWindow は help 型を import しない（移植元コメントどおり） |

`chooseCommands(items, options)`:

- `assertCommandChoiceReady` 失敗は **`Promise.reject`**
- `autoOpen` 既定 `true`、`closeOnComplete` 既定 **`true`**
- confirm → `{ status: "selected", index, command }`（Choice の `item` ではない）
- cancelable cancel → `{ status: "cancelled" }`
- destroy → `WindowOperationCancelledError`
- このライブラリは command handler を呼ばない（`payload` は application 所有）

`HelpWindow.setHelp(content | null)`: 空文字 / 空 RichText は null 扱い。`getHelp()` あり。`onLayoutChanged` で再描画。overflow は 1 ページ目だけ（wrap は有効、2 ページ目は描かない）。
