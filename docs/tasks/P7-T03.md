# P7-T03 — BitmapFont の consumer 契約を明確化する

Status: passed
Assignee: Compose 2.5
Reviewer: Grok 4.6
Phase: 7
Depends: P7-T02

## 目的

`DEFAULT_BITMAP_FONT_ASSET` は sandbox 専用 URL（`/examples/assets/fonts/jf-dot-mplus12/`）を指す。`DEFAULT_` から consumer がそのまま使える標準 asset だと誤解されないようにする。公開 API 互換のため定数自体は残す。

## 対象ファイル

- `src/text/BitmapFontAsset.ts` — JSDoc のみ。値・URL・key は変えない
- `docs/API.md` — `DEFAULT_BITMAP_FONT_ASSET` の説明行
- `docs/SUBMODULE.md` の Font assets 節
- `docs/adr/0002-bitmap-font-loading.md` — sandbox 用である旨を 1 行（任意だが推奨）
- `docs/BACKLOG.md` — 既にある「公開 barrel から外す」候補を消さない。文言が弱ければ P7-T03 の意図（破壊的変更が可能になった段階で sandbox 側へ移す）に合わせる
- `examples/consumer/minimal-submodule-runtime.ts` — P7-T02 の契約が欠けていれば直す（`DEFAULT_` 不使用、consumer 所有 descriptor、nearest）
- `README.md` — consumer 向けコードが `DEFAULT_BITMAP_FONT_ASSET` を使っていないこと、配置・ロード・unload 責任
- `tests/examples/minimal-submodule-consumer.test.ts` および必要なら `tests/package` / `tests/pixi`

`src/**` の load / destroy ロジックは、契約違反があるときだけ直す。違反が無ければコードは触らない。

## 変更方針

### 残すもの

```ts
export const DEFAULT_BITMAP_FONT_ASSET: BitmapFontAsset = {
  key: "jf-dot-mplus12",
  textureURL: "/examples/assets/fonts/jf-dot-mplus12/font.png",
  fontDataURL: "/examples/assets/fonts/jf-dot-mplus12/font.xml",
};
```

公開 barrel からの export も残す。`@deprecated` は付けない（警告を新規公開契約にしてしまう）。JSDoc で次を書く。

- sandbox 用の既定パスである
- 別プロジェクトではこの URL を使わず、consumer 所有の `BitmapFontAsset` を定義する
- 配置・`Assets.load`・unload の責任は consumer
- window `destroy()` は共有 BitmapFont を unload しない

### consumer 例

README の consumer 向けコードと `minimal-submodule-runtime.ts` は `DEFAULT_BITMAP_FONT_ASSET` を使わない。P7-T02 の `GAME_FONT` + `import.meta.url` + nearest を維持または不足分を足す。

nearest の形:

```ts
const font = await Assets.load<BitmapFont>({
  alias: GAME_FONT.key,
  src: GAME_FONT.fontDataURL,
});

for (const page of font.pages) {
  page.texture.source.scaleMode = "nearest";
}
```

### 所有権（文書）

| 責任 | 所有者 |
|---|---|
| `font.png` / `font.xml` / `license.txt` の配置 | consumer の asset pipeline |
| `Assets.load` | consumer（Window 構築前） |
| missing font | `BitmapFontNotLoadedError`（既存） |
| missing glyph | `MissingBitmapGlyphError`（既存） |
| window `destroy()` | 自前 display object のみ。共有 BitmapFont / Assets cache は残す |
| unload / `Assets.reset` | consumer または host 終了時。library は呼ばない |

runtime で GitHub や font builder にアクセスしない契約は維持する。

## 実装上の判断（推測しない）

- 定数を sandbox ファイルへ移動しない（破壊的変更。BACKLOG）
- key を `jf-dot-mplus12` から変えない
- missing font / glyph の throw 条件を緩めない。silent fallback 禁止
- `examples/preloadDefaultBitmapFont.ts` と `examples/main.ts` は sandbox 用として `DEFAULT_BITMAP_FONT_ASSET` を使い続けてよい
- 新しい公開 helper（汎用 `preloadBitmapFont`）は足さない

仕様や公開 API の変更（定数削除を含む）が必要になった場合は実装を継続せず、選択肢を返して停止する。
