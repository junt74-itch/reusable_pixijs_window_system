## 目的

`LogWindow`（append-only、最下部にいるときだけ stick）と `DocumentWindow`（読み取り専用 wrap + scroll、typewriter なし）を Pixi に移す。どちらも Phaser と同じく **`ScrollableWindow` を継承**する。`shouldStickToLatest` は公開 Keep。NineSlice / focus bind は作らない。

## Phaser → Pixi

| Phaser | PixiJS 8.20.1 |
|---|---|
| `scene.add.bitmapText` | `new BitmapText({...})` + `getScrollBody().addChild`。プロパティは `TextWindowBase` と同じ（`text` / `style.fontFamily` / `style.fontSize` / `scale.set` / `tint` / `style.letterSpacing` / `position.set`）。`setText` Phaser API を残さない |
| `createBitmapTextMeasurer(scene, keys)` | 既存 `createBitmapTextMeasurer(host, keys)` |
| `scrollBody.add` | `getScrollBody().addChild` |
| `setScrollContentSize` / `setScrollOffset` | 既存 `ScrollableWindow` API |
| 座標 | `Math.trunc`。UNBOUNDED_LAYOUT_HEIGHT `1_000_000` で wrap してから scroll 高さへ |

`LogWindow.append`: 追加後 `shouldStickToLatest(offset, maxOffset)` が true なら `setOffset(maxOffset)`。`clear` / `getEntries` あり。constructor の `ready` フラグで super 中の `onLayoutChanged` を無視（移植元どおり）。

`DocumentWindow.setDocument` / `getDocument`。set 後 offset 0。typewriter / say は持たない。空 content は labels を消して content size 0。

両クラスとも `layoutRichText` の run ごとに BitmapText。`label.text = run.text`。RichText を BitmapText に直接載せない。未ロード font は `BitmapFontNotLoadedError`。mask `visible = false` に戻さない。
