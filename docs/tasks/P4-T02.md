## Phaser → Pixi

| Phaser | PixiJS 8.20.1 |
|---|---|
| `scene.add.graphics`（cursor） | `new Graphics()` + parent `addChild`。v8 `rect().fill()`。`beginFill` 禁止。blink は既存 `cursorBlinkVisible` |
| CursorRenderer 第 1 引数 `Scene` | parent `Container` で足りる。host が必要なら第 1 引数 `PixiWindowHost` + parent。公開メソッド `draw` / `hide` / `update` / `destroy` 維持 |
| `scene.add.bitmapText`（行ラベル） | `new BitmapText` + `scrollBody.addChild`。プロパティは `TextWindowBase` / `MessageWindow` と同じ。`setText` Phaser API を残さない。`layoutRichText` の run を描く（`label.text = item.label` で RichText を直接載せない） |
| `scene.add.container`（scrollBody） | `new Container()`。clip は既存 `ScrollContentClip` / `ContentClipper`。**mask `visible = false` に戻さない** |
| 行 y / cursor bounds | `Math.trunc`。scroll offset は `position.set(0, Math.trunc(-offset))`（axis y） |
| `fillRect` cursor | `rect(x, y, w, h).fill({ color, alpha })` |

`SelectableWindow` 公開面は移植元どおり（`setItems` / `select` / `getSelectedIndex` / 行ヒット / scroll 合成 / virtualization + overscan）。`onSelectionConfirmed` / `onSelectionCancelled` は Choice が override する protected。

`ChoiceWindow.choose(items, options)`:

- busy → `Promise.reject(ChoiceBusyError)`
- 空リスト / 全部 disabled → `Promise.reject(ChoiceConfigurationError)`
- `autoOpen` 既定 `true` → `ignoreTransitionCancellation(this.open())` + `activate()` + `WindowBase#show()`
- `closeOnComplete` 既定 **`true`**（Message の `false` と違う。移植元どおり）
- confirm → `{ status: "selected", index, item }`
- cancelable の cancel → `{ status: "cancelled" }`
- destroy 中 → `WindowOperationCancelledError`
- `string[]` は `SelectableItem` へ normalize（id は index 文字列、value は label）

行ラベルは wrap しない（SPEC: Choice は 1 行、はみ出しは clip）。`ROW_LABEL_LAYOUT_WIDTH/HEIGHT` の unbounded layout を維持。

## テスト

WebGL / `Application.init` 禁止。stub host / stub BMFont は `tests/pixi/MessageWindow.test.ts` と同じ。入力は `ManualWindowInput`。

`tests/pixi/CursorRenderer.test.ts`（新規、最低限）:

1. `draw` 後に parent へ Graphics が載る。座標は整数
2. `update` が `cursorBlinkVisible` を使う。`WindowBase` ソースに blink が無い
3. `beginFill` / phaser が無い

`tests/pixi/SelectableWindow.test.ts`（新規）:

1. `extends TextWindowBase`。`extends ScrollableWindow` ではない。`src/pixi/ScrollableWindow.ts` を import しない
2. `setItems` 後に visible な BitmapText 行がある。RichText label は run ごとに BitmapText
3. `ManualWindowInput` の down/up で `getSelectedIndex` が動く（open+activate+enable）
4. 行数が viewport を超えるとき scrollBody の y が `Math.trunc(-offset)`。`ScrollableWindow` を継承していない
5. `from "phaser"` / `beginFill` / `new Text(` が無い

`tests/pixi/ChoiceWindow.test.ts`（新規）:

1. `extends SelectableWindow`
2. `choose(["A","B"])` のあと confirm で `{ status: "selected", index: 0 }`（または選択行）
3. 二回目の `choose` は `ChoiceBusyError`。空配列は `ChoiceConfigurationError`
4. `cancelable: true` で cancel → `{ status: "cancelled" }`
5. barrel から `ChoiceWindow` / `ChoiceBusyError` / `ChoiceConfigurationError` を import できる

既存 `tests/selection/SelectionController.test.ts` は壊さない。
