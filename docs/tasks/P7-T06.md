# P7-T06 — `bun run check` と consumer browser smoke test

Status: passed
Assignee: Compose 2.5
Reviewer: Grok 4.6
Phase: 7
Depends: P7-T05

## 目的

援用性改善の品質ゲートを、ローカルと GitHub Actions の両方で同じ `bun run check` に閉じる。consumer 例が typecheck だけでなく HTTP 上で実ファイルへ到達することを自動検証し、browser での起動は手動で確認する。

## 対象ファイル

- `package.json` の scripts のみ（`test:smoke` 追加と `check` への接続）
- `tests/smoke/consumer-http.test.ts`（新規。`test:unit` の列挙には入れない）
- 既存テストや文書が smoke の前提を満たさない場合の **最小修正**（P7-T01〜T05 の漏れ）。公開 API を変えて埋めてはいけない

## smoke の範囲

CI / `bun run check` で保証すること:

1. Vite dev server を一時起動する（port は **4179**、`--strictPort`。既定 5173 と衝突させない）
2. `GET /examples/consumer/minimal-submodule.html` が 200
3. runtime モジュール（HTML が読む `.ts` または Vite が返す URL）が 200
4. consumer 所有フォント `font.xml` と `font.png` が 200
5. プロセスを必ず終了する（失敗時も含む）

保証しないこと:

- WebGL コンテキストの作成
- `say()` / `choose()` の自動操作
- スクリーンショット

WebGL 非搭載の `ubuntu-latest` で落ちるテストにしてはいけない。

## check スクリプト

既存:

```text
bun run test:unit && bun run typecheck && bun run build && bun run test:package && bun run typecheck:consumer
```

これに `test:smoke` を **末尾** へ足す。

```text
bun run test:unit && bun run typecheck && bun run build && bun run test:package && bun run typecheck:consumer && bun run test:smoke
```

`test:unit` に `tests/smoke` を混ぜない（毎回 Vite が立ち上がるのを避ける）。

## 実装上の判断（推測しない）

- Playwright / Puppeteer / Chromium を **devDependencies に足さない**
- `bun` の `spawn` で `vite`（既存 devDependency）を起動する。新規の大きなテストランナー禁止
- タイムアウトは 30 秒程度。listen 待ちはループまたは Vite の ready 出力
- ポート使用中なら失敗（`--strictPort`）。リトライで別ポートへ逃げない
- P7-T01〜T05 の契約テストが欠けていれば足してよいが、新しい Window 機能や公開 API で穴を埋めない
- Actions workflow を増やさない。既存 `bun run check` が smoke を含めば十分

公開 API 変更が必要なら停止する。

## 自動テスト

- `tests/smoke/consumer-http.test.ts` が上記 HTTP 200 を検証する
- `package.json` の `check` が `test:smoke` を含む
- 既存 `bun run check` の前段（unit / typecheck / build / package / consumer typecheck）が残っている

## 手動確認

1. `bun run dev` → http://localhost:5173/examples/consumer/minimal-submodule.html
2. MessageWindow が表示され、確定後に ChoiceWindow が選べる
3. 既定 sandbox http://localhost:5173/ が回帰していない（起動すること）
4. Three overlay http://localhost:5173/three-overlay.html のリンクが README から辿れる（本タスクで Three 実装は変えない）

## 非対象

- 新しい Window 種、日本語禁則、a11y tree、複数 gamepad
- npm / Git URL 公開、LICENSE、version bump
- Three 共有 context の標準化
- Playwright による say → choose 自動操作
- PROGRESS チェックボックス（Grok）、git commit

## 受入条件

1. `bun run check` がローカルで exit 0（unit、typecheck、build、package、consumer typecheck、HTTP smoke）
2. GitHub Actions の `check` workflow が同じ `bun run check` を実行する（P7-T04 のまま）
3. consumer 例が `src/**` を importしていない（既存静的テスト）
4. consumer 向けコードが sandbox 専用フォントパスへ依存しない
5. browser で consumer HTML が起動する（手動）
6. npm / Git URL 導入を利用可能であるように見せていない（P7-T05 の文書契約）

## 実行コマンド

```bash
bun run check
```

手動:

```bash
bun run dev
```
