# P3-T01 — PixiBitmapTextMeasurer / TextWindowBase

Status: passed
Assignee: Compose 2.5

## 目的

BitmapText 専用の measurer と `TextWindowBase` を入れる。layout が使う `base` は XML の `base`（または `lineHeight - baseLineOffset`）であり、Pixi の `baseLineOffset` を `resolveBitmapFontBase` に直接渡さない。Canvas / OS / `PIXI.Text` 禁止。

## 移植元

`/tmp/reusable_phaser_window_system` commit `7cfd3156a5184193fe9e9e63958e5416d277e37e`:

- `src/text/PhaserBitmapTextMeasurer.ts` → `PixiBitmapTextMeasurer`
- `src/text/FallbackBitmapTextMeasurer.ts` の `createBitmapTextMeasurer`
- `src/text/TextWindowBase.ts`
- `tests/text/TextWindowBase.test.ts`（ソース契約。Pixi 置換後も同等の契約を残す）

公開メソッドと layout/render の意味論は維持。第 1 引数 `Scene` は承認済みどおり `PixiWindowHost`。

## Phaser → Pixi

| Phaser | PixiJS 8.20.1 |
|---|---|
| `scene.cache.bitmapFont.get(key)` | 読み込み済み `BitmapFont`。`Assets.get` / `Cache.get`。sandbox / ADR 0002 と同じ key（`DEFAULT_BITMAP_FONT_ASSET.key`）。Pixi 内部の `${key}-bitmap` があるならそれで解決し、選んだ解決をテストで固定する |
| `new PhaserBitmapTextMeasurer(scene, key)` | `new PixiBitmapTextMeasurer(host, key)`。未ロードなら既存 `BitmapFontNotLoadedError` |
| `scene.make.bitmapText` probe + `getTextBounds(true)` | offstage `BitmapText` + bounds。bun 上で renderer なし `new BitmapText` が失敗するときだけ、`font.chars` の `xAdvance` / kerning で `measure` する代替を書いてテストで固定する。どちらの経路でも Canvas `Text` は使わない |
| `entry.data.size` / `lineHeight` / `data.base` | `baseMeasurementFontSize`（または fontSize）、`lineHeight`。**`base` は `resolveBitmapFontBase({ base: lineHeight - baseLineOffset, lineHeight, chars })`。`baseLineOffset` そのものを `base` にしない**（P2-T01 / ADR 0002。jf-dot-mplus12 なら XML `base=11`） |
| `createBitmapTextMeasurer(scene, fontKeys)` | `createBitmapTextMeasurer(host, fontKeys)`。1 キーなら `PixiBitmapTextMeasurer`、複数なら既存 `FallbackBitmapTextMeasurer` |
| `scene.add.bitmapText` を content へ | `new BitmapText({...})` + `getContentContainer().addChild`。`fontFamily` は asset key。`fontSize` / scale / tint / letterSpacing は theme。座標は `Math.trunc` |
| `texture.setFilter(NEAREST)` | font page `texture.source.scaleMode = "nearest"`（preload helper と同じ） |
| `setFont` / `setText` / `setFontSize` / `setScale` / `setTint` / `setLetterSpacing` / `setPosition` / `setVisible` | Pixi v8 BitmapText の対応プロパティ。偽型禁止 |

`hasGlyph` はロード済み font の `chars` を code point で見る。

## TextWindowBase

移植元の公開／protected 契約を維持:

- `setFontKey`
- `layoutTextContent` → `layoutRichText`（`layoutText` 直呼び禁止）
- `renderLines` は `line.runs` を回し、`scaleFontMetrics` + `line.ascent` で y
- `clearText` / `getCurrentLayout` / `onLayoutChanged` / `destroy`（text objects と measurer を先に破棄）
- 未ロード specified font key は `BitmapFontNotLoadedError`
- `layoutTextContent` は `setTheme` しない

`this.scene` は作らない。`this.host`。

## エラーメッセージ

`BitmapFontNotLoadedError` の文言が Phaser `scene.load.bitmapFont` のままなら、Pixi `Assets.load({ alias, src: fontDataURL })` 向けに直す。エラー class 名は変えない。

## テスト

WebGL / `Application.init` 禁止（P2-T04 と同じ）。

- `tests/pixi/PixiBitmapTextMeasurer.test.ts`
  - 未ロード key → `BitmapFontNotLoadedError`
  - stub / 実 XML 値で `base === 11`（`baseLineOffset` を base にしない）
  - `hasGlyph`（ひらがな有、U+2026 等 XML に無い code は無）
  - `measure` が有限の非負整数 width/height
  - `createBitmapTextMeasurer(host, [key])` が単体 measurer、複数キーが `FallbackBitmapTextMeasurer`
  - `from "phaser"` / `PIXI.Text` / `beginFill` が無い
- `tests/pixi/TextWindowBase.test.ts` — 移植元ソース契約を Pixi 語彙に更新（`layoutRichText`、`line.runs`、ascent、`BitmapFontNotLoadedError`、OS/CSS/`Text` 禁止）。`cache.bitmapFont.get` 前提は Pixi の解決経路に置き換える
- 必要なら既存 `tests/text/TextWindowBase.test.ts` は **作らない**（P1 で未コピー）。pixi 側に置く

stub host は P2-T04 と同じ（実 `Container` stage、ticker/canvas/renderer stub）。

## 受入条件

1. `bun run check` が exit 0
2. measurer の `base` が XML `base`（jf-dot-mplus12 なら 11）であり `baseLineOffset`（3）ではない
3. `TextWindowBase` が `PixiWindowHost` + BitmapText のみ
4. `createBitmapTextMeasurer` が公開され、第 1 引数が `PixiWindowHost`
5. `src/core` と `src/text` に pixi import が無い
6. Canvas / OS font / `PIXI.Text` が無い
