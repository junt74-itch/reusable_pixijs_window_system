# P1-T06 — GraphicsWindowRenderer and forbidden imports

Status: passed
Assignee: Compose 2.5
Reviewer: Grok 4.6
Phase: 1

## 目的

Phaser 非依存の chrome renderer（`GraphicsLike` + fake Graphics）を移し、`src/` の phaser / pixi.js import が 0 件であることを検査で固定する。Pixi の Graphics factory と WindowBase はまだ入れない。

## 移植元

commit `7cfd3156a5184193fe9e9e63958e5416d277e37e`（`/tmp/reusable_phaser_window_system` 可）。

## 対象

コピー（ロジック変更禁止）:

- `src/core/GraphicsWindowRenderer.ts`

`src/core/WindowRenderer.ts`:

- `GraphicsLike`, `GraphicsFactory`, `WindowRenderer` はそのまま
- `import type Phaser` と `WindowRendererFactoryContext` / `WindowRendererFactory` は **コピーしない**（`scene: Phaser.Scene` がある。host 置換は P2 の PixiWindowHost と一緒に入れる）

コピーしない:

- `PhaserGraphicsFactory.ts`
- `windowRendererFactory.ts`（`createPhaserGraphicsFactory` 依存）
- `ContentClipper.ts`, `WindowBase.ts`

テスト:

- `tests/core/GraphicsWindowRenderer.test.ts` — 全部（fake GraphicsLike）
- `tests/core/WindowRenderer.injection.test.ts` — **コピーしない**（default factory と Phaser stub）

`src/index.ts` が今回 export してよいもの:

- `GraphicsWindowRenderer`
- types: `WindowRenderer`, `GraphicsLike`, `GraphicsFactory`

export しない: `createDefaultGraphicsWindowRenderer`, `resolveWindowRenderer`, `WindowRendererFactory`, `WindowRendererFactoryContext`, `ContentClipper`

禁止 import 検査（`tests/package/public-exports.test.ts` または新規 `tests/package/forbidden-imports.test.ts`）:

- `src/**` に `from "phaser"` / `from 'phaser'` / `from "pixi.js"` / `from 'pixi.js'` が 0
- `dist/index.js` に `from "phaser"` と `phaser/dist/phaser.esm` が無い
- `package.json` に `phaser` 依存が無い

更新: public-exports、consumer（GraphicsWindowRenderer + fake factory の型検査は可）、`src/README.md`、`docs/API.md`。default renderer factory は Planned。

## 非対象
