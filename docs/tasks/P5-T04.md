## Phaser → PixiJS 8.20.1

| Phaser | PixiJS 8.20.1 |
|---|---|
| `context.scene.textures.exists(key)` | `Cache.has(options.textureKey)`。未ロードは **`MissingWindowSkinError`**。Graphics へ silent fallback しない |
| `textures.get(key).setFilter(NEAREST)` | 解決した `Texture.source.scaleMode = "nearest"` |
| `scene.add.nineslice(...)` | `new NineSliceSprite({ texture, leftWidth, rightWidth, topHeight, bottomHeight, width, height, anchor: 0 })`。`beginFill` 禁止 |
| `setOrigin(0,0)` / `setPosition(0,0)` | `anchor.set(0, 0)`（constructor の `anchor: 0` で可）+ `position.set(0, 0)` |
| `context.root.add(chrome)` | `context.root.addChild(chrome)` |
| `chrome.setSize(w, h)` | `chrome.width` / `chrome.height`。整数。最小は `leftWidth+rightWidth` と `topHeight+bottomHeight` |
| dummy `background` / `frame` | 移植元どおり `UnusedChromeGraphics` 相当の **非公開** `GraphicsLike`（export しない） |
| `applyTheme` | pin どおり **no-op**（atlas を theme 色で塗らない）。`chromeVisible` を新設しない |
| `tileX` / `tileY` | 型は Keep（optional）。省略または `false` は stretch。Pixi `NineSliceSprite` に tile フラグは無い。**`true` なら `WindowConfigError`**（新しい error クラスを作らない。silent stretch 禁止） |
| `frame` | 省略または `0` は `Cache.get(textureKey)` が `Texture` であること。文字列 frame / spritesheet は `MessageWindow.resolvePortraitTexture` と同じ解決でよい。解決不能は `MissingWindowSkinError`。テストは frame 無しでよい |

`createNineSliceWindowRenderer(context, options)` は `new NineSliceWindowRenderer(context, options)` を返す。

初期 nineslice 幅高さは移植元どおり `Math.max(left+right, 1)` / `Math.max(top+bottom, 1)`。その後 `WindowBase` が `resize` する。
