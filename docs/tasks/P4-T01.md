## Phaser → Pixi

| Phaser | PixiJS 8.20.1 |
|---|---|
| `scene.add.bitmapText`（speaker） | `new BitmapText({...})` + `getContentContainer().addChild`。`fontFamily` は theme `fontKey`。座標 `Math.trunc`。API は `TextWindowBase` と同じプロパティ（`text` / `style.fontSize` / `scale.set` / `tint` / `visible` / `position.set`）。`setFont` 等の Phaser API を残さない |
| `scene.add.graphics`（pause △） | `new Graphics()`。v8 は shape-then-fill。`beginFill` 禁止。移植元の fillTriangle 座標を `poly` + `fill({ color: 0xffffff })` に写す |
| `scene.add.image` + `setOrigin(0,0)` + `setDisplaySize` | `new Sprite(texture)`。`anchor.set(0, 0)`。`position.set(0, 0)`。幅高さは `Math.trunc(portrait.width/height)`。NEAREST: `texture.source.scaleMode = "nearest"` |
| `scene.textures.exists(key)` | Pixi の cache。`Cache.has(key)` または `Assets.cache.has`（選んだ解決をテストで固定）。未ロードは `MissingMessagePortraitError`。silent fallback 禁止。偽 `scene.textures` を作らない |
| `scene.cache.bitmapFont.get`（`assertContentFontsLoaded`） | 既存 `resolveLoadedBitmapFont` / `ensureMeasurerForContent`。未ロードは `BitmapFontNotLoadedError` を **reject**（throw したままにせず移植元どおり `Promise.reject`） |
| `ignoreTransitionCancellation(this.open())` | 既存 `src/core/windowOperations.ts` |
| `this.content.add` | `getContentContainer().addChild` |

`say(speaker, content, options)` の既定: `charsPerSecond: 30`、`autoOpen: true`、`closeOnComplete: false`。busy / destroyed は `Promise.reject`。portrait / layout のその他は throw（移植元と同じ振り分け）。

`autoOpen: true` のとき `open()` + `activate()` + `WindowBase#show()`（visibility）。sandbox の `showDemo` とは無関係。

`update` で `controller.update(delta)` → `renderRevealed` → pause indicator の `visible`。destroy は controller.dispose → portrait → speaker → pause Graphics → `super.destroy()`。

layout 予約:

- `getTextBodyOffsetY` = speaker 行（空 speaker なら 0）
- `getTextBodyOffsetX` = `portraitReservedWidth(activePortrait)`
- `getTextLayoutWidth/Height` は移植元どおり。幅が非正なら `WindowLayoutError`

`isTextOperationBusy` は `controller.isBusy()`（font swap 中の `FontSwapBusyError` を維持）。

`onLayoutChanged` は `super.onLayoutChanged(contentBounds)` のあと、進行中テキストがあれば page breaks / speaker / portrait を再計算（移植元）。シグネチャは Pixi の `onLayoutChanged(_contentBounds: WindowBounds)`。

`renderRevealed` は移植元の color run 分割を維持。BitmapText の更新は `TextWindowBase.renderLines` と同じ Pixi プロパティ。座標は整数。

`frame` 付き portrait は Phaser の第 4 引数相当。解決できない frame は typed error（`MissingMessagePortraitError` でよい）。Graphics / OS font へ落とさない。テストは frame 無しでよい。

## テスト

WebGL / `Application.init` 禁止。stub host と stub BMFont は `tests/pixi/TextWindowBase.render.test.ts` と同じ。入力は `tests/helpers/ManualWindowInput.ts`。portrait テクスチャは `Cache.set(key, Texture.EMPTY)`（または 1x1 `Texture`）。

`tests/pixi/MessageWindow.test.ts`（新規）:

1. `extends TextWindowBase`。`src/message/**` に pixi import が無い
2. `say(null, "A")` が busy 中の二回目を `MessageBusyError` で reject。destroy 後は `WindowDestroyedError`
3. 未ロード portrait は `MissingMessagePortraitError`。ロード済み portrait で `Sprite` が content に載り、幅が `Math.trunc(portrait.width)`
4. speaker 非 null のとき speaker `BitmapText` が見え、本文 y が speaker 予約高さを含む
5. `{page}` または layout ページ境界で `pausedForAdvance`。`ManualWindowInput` の `confirm` pressed + `update` で次ページへ進む。pause Graphics が visible 切替する
6. `{color}` トークンで tint の違う BitmapText が複数 visible（`splitLineColorRuns` 経路）
7. `from "phaser"` / `beginFill` / `PIXI.Text` / `new Text(` が MessageWindow ソースに無い
8. barrel から `MessageWindow` を import できる。`assertMessageSayPreflight` は barrel に出さない

既存 `tests/message/*.test.ts` は壊さない。
