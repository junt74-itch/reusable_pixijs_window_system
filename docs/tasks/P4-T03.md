## 対象

`examples/main.ts`、必要なら `index.html` の操作説明、README sandbox 節、`tests/examples/sandbox-entry.test.ts`。

起動は維持: `Application.init` 960×540、`roundPixels: true`、`antialias: false`、`createPixiWindowHost`、`preloadDefaultBitmapFont`、整数倍 letterbox（`app.renderer.resize` 禁止）。

構成:

1. **共有 `PixiWindowInput`** — Message に `ownsInput: true`、Choice に同じ adapter を `ownsInput: false`（移植元どおり）
2. **MessageWindow** — 日本語 + ページ送り（`\f` または layout ページ）。`autoOpen` 既定。glyph は font.xml にある文字だけ（U+2026 等は使わない）
3. **ChoiceWindow** — `["Continue", "Stop"]` 相当（表示は日本語にしてよいが glyph 必須）。`autoOpen` 既定、`closeOnComplete` 既定 true
4. ループ: `await say(...)` → `await choose(...)`。Continue で次 iteration、Stop で停止
5. ticker で両方 `update` + input `update`
6. **演習キー**（`KeyboardEvent.code`。デモ専用 action を PixiWindowInput に足さない）:
   - destroy（pending `say` / `choose` が `WindowOperationCancelledError`）
   - 必要なら open/close/hide/show
   - 対象 window を README に明記
7. 座標 `Math.trunc`。既存 letterbox / `image-rendering: pixelated`

Phase 3 の WindowBase 円 / DemoTextWindow / ScrollableWindow 3 枚は **置き換えてよい**（Phase 4 完了条件は integration）。`DemoTextWindow.ts` が未使用なら残してもよいが barrel に出さない。

`?scene=` 全カタログと `?exercise=` 全分岐は **非対象**（P5）。destroy 中 reject はキー 1 本で足りる。
