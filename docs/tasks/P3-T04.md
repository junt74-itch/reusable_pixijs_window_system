# P3-T04 — 整数座標 / nearest / clip の視覚 fixture

Status: passed
Assignee: Compose 2.5
Reviewer: Grok 4.6
Phase: 3

## 目的

sandbox で Phase 3 完了条件を目視できる状態にする。長文・日本語・複数 fontSize・長いリスト・resize 後 re-layout。整数座標、BMFont nearest、content clip。Message / Selectable / NineSlice は入れない。

## 対象

`examples/main.ts`（と必要なら `index.html` の短い操作説明、README sandbox 節）。

`TextWindowBase` は abstract なので **examples 内** の concrete subclass（barrel に出さない）:

```ts
class DemoTextWindow extends TextWindowBase {
  public show(content: WindowTextContent): void {
    this.paint(this.layout(content));
  }
  // layout/paint は protected を公開する薄いラッパ
}
```

起動手順（既存 Application.init 960×540、`roundPixels: true`、`antialias: false`、`createPixiWindowHost`、`preloadDefaultBitmapFont` は維持）:

1. **DemoTextWindow** — RichText。日本語 + 複数 `fontSize`（12 と 24）。`"こんにちは ABC 123"` を消さない（span の一部で残してよい）
2. **ScrollableWindow**（`showScrollbar: true`）— scrollBody に多数の BitmapText 行（ひらがなを含む。glyph は font にある文字だけ。U+2026 等は使わない）。`setScrollContentSize` を行高×行数で設定
3. 両方 `void open()` + `activate()`。ticker で `update`
4. overflow 円は WindowBase デモ用に残してよい（Text または Scroll の content / body）。clip されること
5. **目視できる大きさ:** ブラウザを広げても論理 960×540 が潰れて 12px が消えないこと。`#app` を 960×540 に固定（letterbox）するか、stage を整数 scale でフィット。renderer を無制限に client 全面へ伸ばして 1:1 のまま放置しない
6. font page `scaleMode = "nearest"`（既存 preload で足りる）
7. 座標は `Math.trunc`

入力:

- 既存 `KeyR` / `KeyP` / `KeyC` / `Space` / `KeyX` は維持してよい（対象 window を明記）
- Scroll 用に `PixiWindowInput` を **その ScrollableWindow に** 渡す（`ownsInput` は sandbox の所有方針に合わせる）。PageUp/PageDown / wheel でスクロールできること。デモ専用キーを PixiWindowInput に足さない

`beginFill` / `phaser` / `PIXI.Text` 禁止。
