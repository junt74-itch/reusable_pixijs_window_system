## 目的

Pixi 公式の **単一 WebGL context 共有**を **任意例**として置く。標準経路は P6-T01 の別 canvas overlay のまま。README / API は「標準ではない」と明記する。`src/` 公開 API は増やさない。共有を標準にするかは人間判断（BACKLOG）。

## 移植・参照

- 標準例（壊さない）: `three-overlay.html` / `examples/three-overlay.ts`
- 公式手順: [Mixing PixiJS and Three.js](https://pixijs.com/8.x/guides/third-party/mixing-three-and-pixi)（`context` 共有、`stencil: true`、`clearBeforeRender: false`、両方 `resetState`）
- PixiJS **8.20.1** の `Application.init` で同等を実現する。`createPixiWindowHost(app)` を使う（生 `WebGLRenderer` だけにして host を捨てない）

`examples/main.ts` と `three-overlay.html` は **変えない**。

## 実装契約

1. canvas は **1 枚**（Three `WebGLRenderer.domElement` を Pixi も使う）。P6-T01 のような 2 枚重ねではない
2. Three: `new WebGLRenderer({ antialias: false, stencil: true })`。`setSize(960, 540, false)`。最小の回転 cube
3. Pixi: `new Application()` のあと `await app.init({ ... })`。**Three の context を渡す**。`clearBeforeRender: false`（または毎フレーム `clear: false`）。`roundPixels: true`。`antialias: false`
4. 各フレーム: Three `resetState` → Three `render` → Pixi `resetState` → Pixi 描画（UI が 3D の上に残ること）。Application 既定の auto-render が Three を消す／覆うなら auto-render を止めて `app.renderer.render({ container: app.stage, clear: false })` を明示する
5. `createPixiWindowHost(app)` + `MessageWindow` または `WindowBase` 1 枚。font は既存 `preloadDefaultBitmapFont`
6. letterbox: 論理 960×540、CSS 整数倍。親は `#shared-root`（`#app` 相当の全画面 flex 中央）。`app.renderer.resize` で論理サイズを変えない
7. `src/` に `from "three"` を足さない。`any` 禁止。`phaser` 禁止

init のフィールド名が 8.20.1 の型と合わないときは **推測で Application を捨てない**。合わない点をチケット範囲で止めて報告する（新しい Host 型を作らない）。
