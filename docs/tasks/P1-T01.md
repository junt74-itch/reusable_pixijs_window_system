# P1-T01 — Core theme, types, transition

Status: passed
Assignee: Compose 2.5
Reviewer: Grok 4.6
Phase: 1

## 目的

移植元のエンジン非依存 core（theme / types / TransitionController / windowOperations）を、挙動を変えずに移す。WindowBase も Pixi もまだ入れない。

## 移植元

- リポジトリ: `https://github.com/junt74-itch/reusable_phaser_window_system`
- commit: `7cfd3156a5184193fe9e9e63958e5416d277e37e`
- ローカルがあれば `/tmp/reusable_phaser_window_system` を読んでよい。本リポジトリへ Phaser 版を入れない。

## 対象

**コピーしてよい（ロジック変更禁止。Phaser 名が無いことを確認してそのまま移す）:**

- `src/core/types.ts`
- `src/core/theme.ts`
- `src/core/TransitionController.ts`
- `src/core/windowOperations.ts`
- `tests/core/theme.test.ts`
- `tests/core/TransitionController.test.ts`
- `tests/core/WindowBase.lifecycle.test.ts`（このファイルは WindowBase を import しない。ignoreTransitionCancellation と destroy 順序の純契約）

**更新してよい:**

- `src/index.ts` — 下記の公開 export を追加。`VERSION` は残す
- `package.json` の `test:unit` に `tests/core` を足す
- `tests/package/public-exports.test.ts` — 新しい公開名が dist と d.ts にあること
- `examples/consumer/readme-example.ts` と `submodule-source.ts` — Window クラスを使わず、`resolveWindowTheme` など今回の export を型検査してよい
- `src/README.md` — `core/` に theme / transition があること。未実装の WindowBase を完成したように書かない
- `docs/API.md` の Current surface に、実際に export した symbol を足す。未実装 class の利用例は置かない

`src/index.ts` が今回 export してよいもの（移植元 barrel と同じ名前）:

- types: `WindowConfig`, `WindowPadding`, `WindowTheme`, `ResolvedWindowTheme`, `WindowPhase`, `WindowBounds`, `WindowStateSnapshot`, `BitmapTextStyle`, `CursorStyle`
- errors: `WindowConfigError`, `WindowOperationCancelledError`, `WindowDestroyedError`, `WindowLayoutError`
- `resolveWindowTheme`, `validateWindowConfig`, `computeContentBounds`
- `TransitionController` と `TransitionState`, `TransitionSubscription`

`ignoreTransitionCancellation` と `windowOperations.ts` は **export しない**（internal）。

## 非対象

- `WindowBase`, `ContentClipper`, `GraphicsWindowRenderer`, `PhaserGraphicsFactory`, `windowRendererFactory`
- pixi.js の import（`src/core` にも `src/index.ts` にも置かない）
- phaser の import、`any`、偽 Phaser 型
- input / text / message / その他 Phase 1 後続タスク
- sandbox の描画変更
- 名称変更やリファクタ
- 互換性マップ / PORTING_PLAN / PROGRESS / 方針 md の改稿
- git commit / push

## 受入条件

1. `bun run check` が exit 0
2. 移植元と同じ入力で theme / transition の unit test が通る
3. `src/core/**` に `phaser` も `pixi.js` も無い
4. `ignoreTransitionCancellation` が公開 barrel に出ない
5. Window / Host クラスがまだ無い
6. `dist/index.d.ts` に `any` が無い

```bash
bun run check
```
