# P3-T02 — RichText 描画と missing glyph 検査

Status: passed
Assignee: Compose 2.5
Reviewer: Grok 4.6
Phase: 3

## 目的

`TextWindowBase` の RichText 描画を **実行**で固定する（P3-T01 のソース契約だけでは不十分）。複数 `fontSize` の run が別 `BitmapText` になり、欠損 glyph は `MissingBitmapGlyphError` で止まり silent fallback しない。

## 前提

P3-T01 済み。`layoutRichText` / `MissingBitmapGlyphError` / `assertMeasurerHasGlyphs` は Phase 1 で landed。このタスクは **描画経路** と **window 経由の missing glyph**。

移植元: `/tmp/reusable_phaser_window_system` commit `7cfd315` の `TextWindowBase.renderLines` / `layoutTextContent`。新規公開クラスは作らない。

## 対象

- `src/pixi/TextWindowBase.ts` — 描画意味論を変えない。bug があれば直す（OS/Canvas/`Text` を足さない）
- `tests/pixi/TextWindowBase.render.test.ts`（新規。WebGL / `Application.init` 禁止）

テスト用の **concrete subclass** を test ファイル内に置く（本番 barrel に出さない）:

```ts
class TestTextWindow extends TextWindowBase {
  public layout(content: WindowTextContent) {
    return this.layoutTextContent(content);
  }
  public paint(lines: readonly LayoutLine[]) {
    this.renderLines(lines);
  }
}
```

stub host / stub font は `tests/pixi/PixiBitmapTextMeasurer.test.ts` と同じ（実 `Container` stage、`Cache.set` で font、ticker/canvas/renderer stub）。

## 受入テスト

1. **mixed fontSize:** RichText で span 2 つ（例: `"Hello "` fontSize 12 と `"あ"` fontSize 24）。`layout` → `paint` のあと `getContentContainer()` の `BitmapText` が 2 つ以上 visible。それぞれの `style.fontSize` が run の値。`fontFamily` は asset key。座標は整数（`x`/`y` が `Math.trunc` 済み）。
2. **日本語:** ひらがなを含む文字列が layout でき、少なくとも 1 つの `BitmapText.text` にその文字が残る。
3. **missing glyph:** font に無い code（U+2026 `…` または U+2022 `•`）を渡すと `MissingBitmapGlyphError`。空文字や OS font に置き換えない。
4. **unloaded span fontKey:** 未ロード key を span に指定すると `BitmapFontNotLoadedError`（layout 前の `ensureMeasurerForContent`）。
5. **re-layout:** `setSize` のあと同じ content を再 `layout`/`paint` しても throw しない。
6. ソースに `from "phaser"` / `new Text(` / `Arial` / `beginFill` が無い（既存ソース契約テストは残す）。

`PixiBitmapTextMeasurer` の `measureUsingCharMetrics` が欠損 glyph を silently skip しても、**layout 経路**は `assertMeasurerHasGlyphs` で先に落とすこと。layout を迂回して skip する API を足さない。
